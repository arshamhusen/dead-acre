# Dead Acre

A top-down zombie shooter set in a post-war Hulhumalé, built with Phaser 3 in a single HTML file. Open `index.html` in a browser to play. All art and sound are generated in code.

Controls: WASD to move, mouse to aim, click to shoot, Q to switch guns, P to pause, M for sound. On phones, the left thumb moves and the right thumb aims and fires.
